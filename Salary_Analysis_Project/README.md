# Salary Analysis – 3000+ Gross Salary Survey

## Project Goal
Analyze salary distribution and identify key factors influencing income.

## Tools Used
- Python (Pandas, Matplotlib)
- SQL
- Power BI

## Key Questions
- How does experience affect salary?
- Does education level impact income?
- What is the salary distribution?

## Data Cleaning
- Renamed columns
- Fixed mixed data types (experience column)
- Removed non-numeric characters
- Created salary_per_hour feature

## Key Insights
- Salary distribution is right-skewed
- Experience positively correlates with salary
- Higher education shows higher median salary
